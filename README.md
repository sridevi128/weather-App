# Calculator Python

A simple calculator program built using Python.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Shows an error for invalid operators

## How to Run

1. Make sure Python is installed.
2. Open the terminal.
3. Run the program:

```bash
python Calculator.py
